D — Primary in graph + satellite packs

Keep one battery in the classic graph position for flow lines. Extra packs hang below as smaller satellites — useful for plug-in stations (#276) that should not rewrite solar↔grid math, or for “display_only” packs.

  • Clear hierarchy: main storage vs secondary packs
  • Needs a role / flow flag in config
  • Taller card; more layout complexity than A
battery:
  - name: Main
    role: primary          # participates in distribution
    entity: sensor.main_batt
    state_of_charge: sensor.main_soc
  - name: Plug-in
    role: satellite        # display / home-attached
    entity: sensor.plug_batt
    state_of_charge: sensor.plug_soc
  - name: Garage
    role: satellite
    entity:
      consumption: sensor.garage_out
      production: sensor.garage_in
    state_of_charge: sensor.garage_soc
